# 余额宝资金流入流出预测

> 阿里巴巴天池「资金流入流出预测-挑战Baseline」参赛项目
> 从朴素基线到随机森林 + 模型融合的完整迭代记录

## 一、项目背景

余额宝（蚂蚁金服）每天有海量用户的资金申购与赎回。准确预测未来每天的资金流入/流出总量，对平台的流动性管理至关重要。

**任务**：根据 2013-07 至 2014-08 的历史数据，预测 2014 年 9 月 1~30 日每天的总申购额（purchase）和总赎回额（redeem）。

**评估指标**：申购得分占 45% + 赎回得分占 55%，误差越小得分越高（满分约 300）。

## 二、数据与探索

- `user_balance_table.csv`（157MB）：约 3 万用户、14 个月的逐日申购/赎回明细；
- 按天聚合后得到 427 天的日总申购、日总赎回。

**探索发现**：

1. 申购从早期每天约 2000 万分，涨到 8 月底每天约 2.5 亿分——**存在强上升趋势**；
2. 申购/赎回比例从早期的约 6:1 收敛到 8 月底的近 1:1——基金从快速增长进入稳定期；
3. 存在明显的「星期几」规律：**周一最高、周六最低**。

## 三、方法演进（核心：迭代）

### v1 朴素基线：最近 30 天均值 → 76.69 分

把最近 30 天的平均申购/赎回，当作 9 月每天的预测。忽略趋势和周期性。

### v2 特征工程：星期几基线 → 111.30 分（+45%）

按「星期几」分组求平均，9 月每天用对应星期几的均值预测。抓住了最主要的周期性规律。

### v3 随机森林（日历特征）→ 回测显示不如 v2

给随机森林喂「星期几、几号、几月、第几天、是否周末、天数序号」等日历特征。

**结果：回测误差反而比 v2 高。** 结论——**特征比算法重要**：一个朴素的星期几基线，能打败用弱特征训练的随机森林。

### v4 随机森林 + 滞后特征 → 赎回反超

加入滞后特征（昨天值、上周同期值、最近 7 天均值），让模型「吃到最近的量级」。

结果：赎回的误差反超星期几基线；申购仍略弱于基线。

### v5 模型融合（最终方案）

申购用「星期几基线」、赎回用「随机森林 + 滞后特征」，拼成最终提交文件。

核心思想：**申购和赎回是两个不同的问题，应分别用各自最优的模型。**

## 四、核心收获

1. **特征工程 > 算法**：同样的随机森林，特征不同，结果天差地别。
2. **回测（留出法验证）**：提交次数有限时，先在本地验证模型，避免浪费提交机会。
3. **滞后特征**：时间序列预测里「用过去的值预测未来」是关键技巧。
4. **递归预测**：预测未来多天时，把预测值回填作为下一天的特征，误差会累积。
5. **模型融合**：不迷信单一模型，谁在哪个指标上强就用谁。

## 五、技术栈

- Python
- pandas（数据读取、聚合、特征构造）
- matplotlib（可视化）
- scikit-learn（RandomForestRegressor）

## 六、代码结构

- `plot_daily.py`：读取 + 按天聚合 + 画历史曲线
- `step2_submit.py`：v1 朴素基线
- `step3_weekday.py`：v2 星期几基线
- `step4_randomforest.py`：v3 随机森林 + 回测
- `step5_rf_lag.py`：v4 随机森林 + 滞后特征
- `step6_combine.py`：v5 模型融合（最终提交）
